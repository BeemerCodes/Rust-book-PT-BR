# Primeiros Passos

Vamos começar sua jornada com Rust! Há muito para aprender, mas toda jornada começa em algum lugar. Neste capítulo, vamos falar sobre:

- Instalando Rust no Linux, macOS e Windows
- Escrevendo um programa que imprime `Hello, world!`
- Usando o `cargo`, o gerenciador de *packages* e sistema de build do Rust
