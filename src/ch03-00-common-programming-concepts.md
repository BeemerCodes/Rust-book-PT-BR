# Conceitos Comuns de Programação

Este capítulo aborda conceitos que aparecem em quase todas as linguagens de programação e como eles funcionam no Rust. Muitas linguagens de programação têm muito em comum em sua essência. Nenhum dos conceitos apresentados neste capítulo é exclusivo do Rust, mas vamos discuti-los no contexto do Rust e explicar as convenções em torno do seu uso.

Especificamente, você aprenderá sobre variáveis, tipos básicos, funções, comentários e fluxo de controle. Esses fundamentos estarão presentes em todo programa Rust, e aprendê-los cedo lhe dará uma base sólida para começar.

> #### Palavras-chave
>
> A linguagem Rust possui um conjunto de _palavras-chave_ (*keywords*) reservadas exclusivamente para uso da linguagem, assim como em outras linguagens. Tenha em mente que você não pode usar essas palavras como nomes de variáveis ou funções. A maioria das palavras-chave tem significados especiais, e você as usará para realizar várias tarefas em seus programas Rust; algumas ainda não têm funcionalidade associada, mas foram reservadas para recursos que podem ser adicionados ao Rust no futuro. Você pode encontrar a lista de palavras-chave no [Apêndice A][appendix_a]<!-- ignore -->.
