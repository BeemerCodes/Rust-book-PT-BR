# Usando Structs para Estruturar Dados Relacionados

Uma _struct_, ou _estrutura_, é um tipo de dados personalizado que permite
agrupar e nomear vários valores relacionados que formam um conjunto com
significado. Se você já tem familiaridade com alguma linguagem orientada a
objetos, uma struct é parecida com os atributos de dados de um objeto. Neste
capítulo, vamos comparar e contrastar tuplas com structs para construir sobre o
que você já sabe e mostrar quando structs são uma forma melhor de agrupar dados.

Vamos demonstrar como definir e instanciar structs. Também vamos discutir como
definir funções associadas — especialmente o tipo de função associada chamado
de _métodos_ — para especificar o comportamento ligado a um tipo struct. Structs
e _enums_ (abordados no Capítulo 6) são os blocos fundamentais para criar novos
tipos no domínio do seu programa e aproveitar ao máximo a verificação de tipos
em tempo de compilação do Rust.
