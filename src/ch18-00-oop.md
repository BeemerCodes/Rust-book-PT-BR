# Recursos de Programação Orientada a Objetos

<!-- Old headings. Do not remove or links may break. -->

<a id="object-oriented-programming-features-of-rust"></a>

A programação orientada a objetos (POO) é uma forma de modelar programas.
Objetos, como conceito de programação, foram introduzidos na linguagem Simula
na década de 1960. Esses objetos influenciaram a arquitetura de programação de
Alan Kay, na qual objetos trocam mensagens entre si. Para descrever essa
arquitetura, ele cunhou o termo *programação orientada a objetos* em 1967.
Muitas definições concorrentes descrevem o que é POO e, segundo algumas dessas
definições, Rust é orientada a objetos, mas, segundo outras, não é. Neste
capítulo, exploraremos certas características que são comumente consideradas
orientadas a objetos e como essas características se traduzem para o Rust
idiomático. Em seguida, mostraremos como implementar um padrão de projeto
orientado a objetos em Rust e discutiremos as vantagens e desvantagens (*trade-offs*)
de fazê-lo em comparação com implementar uma solução aproveitando alguns dos
pontos fortes do próprio Rust.
